# 🐶🐱 Classificação de Cães e Gatos com Redes Neuronais Convolucionais (CNN)

Projeto desenvolvido para classificação binária de imagens (cão vs. gato) utilizando técnicas avançadas de Visão Computacional e Deep Learning com arquitetura CNN.

## 🎯 Objetivo
Construir e treinar um modelo de Rede Neuronal Convolucional (CNN) capaz de analisar imagens coloridas e classificar corretamente se a imagem contém um cão ou um gato, aprendendo padrões visuais como bordas, texturas e formas de maneira automatizada.

## 🛠️ Tecnologias e Bibliotecas Utilizadas
- **Linguagem:** Python
- **Framework de Deep Learning:** TensorFlow / Keras
- **Processamento e Manipulação de Dados:** NumPy, OS, ZipFile, Random, Shutill
- **Visualização de Dados:** Matplotlib

## 📂 Estrutura e Etapas do Projeto
1. **Definição do Problema:** Aplicação de classificação binária direcionada ao reconhecimento automático de animais de estimação.
2. **Pré-processamento de Imagens:** Extração, organização do conjunto de dados (ZIP) e normalização das entradas.
3. **Construção do Modelo CNN:** Arquitetura composta por camadas convolucionais, pooling e camadas densas de classificação.
4. **Treino e Avaliação:** Monitorização do desempenho através de `ModelCheckpoint` e métricas de precisão/perda.
